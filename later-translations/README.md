# Wersje ES i EN — do przetłumaczenia

Strona została przebudowana według makiety z Canvy (gałąź `redesign-canva`).
Teksty hiszpańskie i angielskie w tym folderze są z poprzedniej wersji landingu
i mają stare klucze. Po akceptacji wersji polskiej tłumaczymy nowy `src/i18n/pl.ts`
na `es.ts` i `en.ts`, przenosimy je z powrotem do `src/i18n/`, a strony
z `pages-es` i `pages-en` do `src/pages/es` i `src/pages/en`.
